## Direction contract

THESIS: Angelia is a wire service for releases. Every new version is a bulletin on the wire: slug, priority, dateline,
body. The page refuses the category default of a dark SaaS hero with feature cards and a terminal screenshot.

OWN-WORLD: Midnight indigo ground (#14123A → #1E1B4B) like the wire room after hours; canary wire-copy paper
(#FDE68A on light docs, gold #FBBF24 rules) for bulletins; perforated five-hole Baudot tape in gold as the recurring
rule and divider. Archivo (condensed widths for slugs, normal for text), JetBrains Mono only for code, slugs and data.
No cards; bulletins, slugs, routing slips.

STORY: a release happens upstream → it arrives on the wire as a bulletin → priority from the bump → routed to
desks (webhook, GitHub dispatch, chat, agents). Then: install in three commands, then the real Home Assistant story.

FIRST VIEWPORT: wordmark, one-line offer ("The self-hosted release event bus"), a live canvas teletype printing
sample bulletins (labelled sample) onto canary paper while gold tape runs above; primary action "Get started",
secondary "Watch the 90-second tour".

SIGNATURE: the teletype: each bulletin types out, its priority stamp lands (MAJOR = FLASH, MINOR = BULLETIN,
PATCH = ROUTINE), then routing lines strike to the four desks. Reduced motion shows a static set.

RISK: monospace-as-costume; keep mono to slugs, data and code only, text in Archivo.
