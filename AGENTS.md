# AGENTS.md — how to work in `docs`

This repository is part of [Angelia](https://github.com/angelia-dev/angelia), built mostly by **AI coding agents** working with a human maintainer. It holds the Angelia website and user documentation.

The rules of the core repository apply here: read [angelia/AGENTS.md](https://github.com/angelia-dev/angelia/blob/main/AGENTS.md) (picking issues, when to stop and ask a human, Graft trailers, definition of done) and [docs/ESTIMATION.md](https://github.com/angelia-dev/angelia/blob/main/docs/ESTIMATION.md) (executor, complexity and model).

## Specific to this repository
- Docs must match released behaviour; link the source issue or PR for every new page.
- Examples must be runnable (copy-paste) and tested where possible.
- No real secrets, tokens or private hostnames in examples.
